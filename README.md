Adidas Sales Analysis Dashboard

## Overview
An interactive Tableau dashboard analyzing Adidas U.S. sales data to uncover
trends in revenue, profitability, product performance, and geographic markets.

##  Business Objective
The goal of this project was to transform raw transactional sales data into
actionable business insights that could support sales and strategic decisions.

##  Dashboard Analysis

The dashboard explores:

- Total Sales and Operating Profit
- Sales performance by state
- Regional sales performance
- Product and retailer performance
- Sales trends over time
- Geographic distribution of revenue

##  Tools & Skills

**Tools:** Tableau, Microsoft Excel

**Skills:** Data Visualization • Business Intelligence • KPI Analysis •
Geographic Analysis • Sales Analytics • Dashboard Development
